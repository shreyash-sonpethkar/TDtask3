# HTML & CSS Selectors Practice

This project is a simple practice exercise created using **HTML5** and **CSS3** to understand the fundamentals of CSS selectors and styling. It demonstrates how different selectors can be used to target and style specific HTML elements.

## Features

* Styling using **Class Selectors**
* Styling using **ID Selectors**
* Background color customization
* Text color customization
* Styling specific words using the `<span>` element
* Link styling with pseudo-class selectors
* Using `:first-child`
* Using `:last-child`
* Using `:nth-child()`

## Technologies Used

* HTML5
* CSS3

* Element Selector

* `:last-child`
* `:nth-child()`

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in any modern web browser.

## Learning Objectives

* Understand HTML document structure.
* Learn how CSS selectors work.
* Practice applying styles using classes and IDs.
* Explore pseudo-class selectors.
